I believe that the best way to learn programming is by building things.

Therefore, instead of only watching tutorials or reading documentation, I will try to:

1. Learn a concept
2. Understand how it works
3. Write the code myself
4. Practice with small examples
5. Build a mini-project
6. Solve problems and debug errors
7. Apply the concept in a real project
8. Document my learning in this repository
